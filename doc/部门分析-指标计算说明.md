# 部门分析 — 指标计算说明

## 一、页面概览

部门分析页面按事业部（如 CBG、EBG、SMBG 等）对收入、成本、毛利、订单等核心财务指标进行拆解分析，展示各部门的贡献对比。支持进一步下钻至产品维度，查看各业务线产品的收入与毛利率情况。

> **注意**：本说明文档覆盖 L1-L4 下钻分析流程（入口为 DrillDownPage，通过 `report_id` 参数控制时间范围）。独立的"部门分析"页面（DepartmentAnalysisPage）使用不同的指标体系和筛选方式，不在此文档范围内。

页面数据通过 `report_id` 参数控制时间范围，无前端独立筛选器，部门范围由当前登录用户的权限自动限定。

---

## 二、指标列表

### L1 总体概览指标

| 指标名称 | 计算说明 | 数据来源 | 格式 |
|---------|---------|---------|------|
| 总收入(万元) | 所有符合条件记录的收入合计值 | `agg_period_summary` 表按周期聚合后累加 | 万元，保留2位小数 |
| 总成本(万元) | 所有符合条件记录的成本合计值；当成本全部为0时显示为空（表示无成本数据） | `agg_period_summary` 表按周期聚合后累加 | 万元，保留2位小数，可能为空 |
| 总毛利(万元) | 总收入减去总成本；当成本数据不可用时显示为空 | 由总收入与总成本计算得出 | 万元，保留2位小数，可能为空 |
| 平均毛利率(%) | 总毛利除以总收入再乘以100，反映整体盈利水平；当成本数据不可用时显示为空 | 由总毛利与总收入计算得出 | 百分比数值（如 25.50 表示 25.50%），保留2位小数，可能为空 |
| 总订单数 | 所有符合条件记录的订单数量合计 | `agg_period_summary` 表 `order_count` 字段按周期聚合后累加 | 整数 |

### 部门维度指标（L1 部门表格 + L2 部门产品表格）

| 指标名称 | 计算说明 | 数据来源 | 格式 |
|---------|---------|---------|------|
| 部门 | 事业部名称（如 CBG、EBG、SMBG 等），对应数据库 `bgbu` 字段 | `agg_period_summary` 表中的 `bgbu` 字段 | 文本 |
| 收入(万元) | 该部门下所有记录的收入合计 | `agg_period_summary` 表按部门汇总 | 万元，保留2位小数 |
| 成本(万元) | 该部门下所有记录的成本合计；当该部门下所有记录的成本均为0时返回空值 | `agg_period_summary` 表按部门汇总 | 万元，保留2位小数，可能为空 |
| 毛利(万元) | 该部门的收入减去成本；当成本数据不可用时显示为空 | 由部门收入与成本计算得出 | 万元，保留2位小数，可能为空 |
| 毛利率(%) | 该部门的毛利除以收入再乘以100；当成本数据不可用时显示为空 | 由部门收入与成本计算得出 | 百分比数值（如 25.50 表示 25.50%），保留2位小数，可能为空 |
| 订单数 | 该部门下的订单数量 | `agg_period_summary` 表 `order_count` 字段 | 整数 |

> **L2 部门产品表格额外指标**：点击部门行进入 L2 后，表格还包含以下产品级指标（见下方"产品维度指标"）。

### 产品维度指标（L1 产品表格 + L2 部门产品表格）

| 指标名称 | 计算说明 | 数据来源 | 格式 |
|---------|---------|---------|------|
| 产品 | 产品/项目名称 | `agg_dimension_summary` 表中的 `dim_value` 字段 | 文本 |
| 类别 | L1 全局产品表固定显示为"业务线"；L2 部门产品表固定显示为"产品线" | 后端根据查询路径硬编码 | 文本 |
| 收入(万元) | 该产品下所有记录的收入合计 | `agg_dimension_summary` 表按产品汇总 | 万元，保留2位小数 |
| 成本(万元) | 该产品下所有记录的成本合计；当该产品下所有记录的成本均为0时返回空值 | `agg_dimension_summary` 表按产品汇总 | 万元，保留2位小数，可能为空 |
| 毛利率 | 该产品的毛利（收入减成本）除以收入；当成本数据不可用时显示为空。后端返回 0~1 的小数比率（如 0.255），前端乘以100后转为百分比显示（如 25.50%） | `agg_dimension_summary` 表按产品计算 | 0~1 小数比率，前端转为百分比，保留2位小数 |
| 销量 | 该产品下的订单数量 | `agg_dimension_summary` 表 `order_count` 字段 | 整数 |

## 三、筛选条件说明

| 筛选条件 | 说明 |
|---------|------|
| 时间范围 | 通过 `report_id` 参数控制。当 `report_id` 为 `"default"` 时不筛选时间，返回全部周期数据；否则按 `report_id` 前缀匹配对应周期的数据（如 `report_id=2026-05` 匹配 `period LIKE '2026-05%'`） |
| 部门范围 | 由登录用户的权限自动限定：管理员（`bgbu=ALL`）可查看全部部门数据；非管理员仅能查看所属部门的数据。该限制通过 JWT token 中的 `user.department` 字段自动生效，在后端强制执行 |
| 前端筛选器 | 本页面（L1-L4 下钻流程）不提供独立的筛选下拉控件，筛选条件均通过路由参数和用户权限自动控制 |

**导航交互：**
- 点击部门行可下钻至 L2 页面（按 `department_id`），查看该部门下的产品列表
- 点击产品行可下钻至 L3 页面（按 `product_id`），查看该产品的交易记录列表
- L3 点击交易记录可下钻至 L4 页面，查看单条交易的详细信息

## 四、注意事项

1. **成本为空的处理**：当某维度下所有记录的成本均为0时，总成本、总毛利、毛利率均返回空值（null），前端应展示为"--"或类似占位符，而非0。后端通过 `cost_unavailable` 字段标记该状态。

2. **毛利率的两种返回格式**：
   - 在 L1 总体概览和部门维度中，`avg_margin`（总览）和 `margin`（部门）后端直接返回百分比数值（如 25.50 表示 25.50%）
   - 在产品维度中，`margin` 后端返回 0~1 的小数比率（如 0.255），前端需乘以100后转为百分比显示（25.50%）。产品维度的 `margin` 保留4位小数精度，部门和总览保留2位

3. **部门权限自动过滤**：非管理员用户无法通过任何方式查看其他部门数据，该限制在后端强制生效，不依赖前端控制。所有下钻路径（L2/L3/L4）均继承此权限限制。

4. **金额格式**：所有金额类指标（收入、成本、毛利）后端返回原始数值（单位：元），前端通过 `toWan()` 函数转换为万元后展示，保留2位小数，使用千分位分隔符（如 1,234.56）。

5. **下钻数据联动**：L1-L4 共用同一套数据源（`agg_period_summary`、`agg_dimension_summary`、`agg_order_summary` 表），下钻时筛选条件自动继承当前页面的时间范围和部门权限。

6. **数据来源表说明**：
   - `agg_period_summary`：周期汇总表，按 `(period, bgbu)` 聚合，存储收入、成本、毛利、订单数等
   - `agg_dimension_summary`：维度汇总表，按 `(period, bgbu, dim_type, dim_value)` 聚合，`dim_type` 包括 `product_line`、`customer`、`sales_product`、`contract_type` 等
   - `agg_order_summary`：订单明细表，按 `(period, bgbu, order_id)` 聚合，存储单笔交易的收入、成本、毛利等信息
