# 产品分析 — 指标计算说明

## 一、页面概览

产品分析页面用于按产品线及销售产品维度拆解分析收入、毛利贡献及结构风险。该页面支持对比各产品线的业务贡献度及毛利率水平，帮助财务及业务人员识别高贡献产品线与低效产品线。

**数据维度：** 产品线维度（product_line）或销售产品维度（sales_product）+ 财务指标（收入、毛利、毛利率、负毛利分析）

**支持的筛选条件：** 期间维度（月度/季度/年累计/自定义）、报告期、对比基期（同比/环比）、产品线、二级维度（客户/合同类型）

## 二、指标列表

### （一）核心 KPI 指标（页面顶部概览）

| 指标名称 | 计算说明 | 数据来源 | 格式 |
|---------|---------|---------|------|
| 营业收入 | 选定期间内所有产品线（或指定产品线）的营业收入总额 | 期间汇总表按期间聚合 | 万元，保留整数（KPI卡片） |
| 毛利额 | 选定期间内所有产品线（或指定产品线）的毛利总额，即营业收入减去不含税成本 | 期间汇总表按期间聚合 | 万元，保留整数（KPI卡片） |
| 毛利率 | 毛利额占营业收入的百分比，反映整体盈利水平。计算公式：毛利额 / 营业收入 x 100% | 由毛利额与营业收入计算得出 | 百分比，保留两位小数 |
| 负毛利产品占比 | 负毛利产品（毛利率为负的产品）的数量占总产品数量的百分比。用于识别亏损产品的覆盖面 | 由产品线维度明细数据计算得出 | 百分比，保留两位小数 |

### （二）明细层指标（产品线/销售产品明细表）

| 指标名称 | 计算说明 | 数据来源 | 格式 |
|---------|---------|---------|------|
| 维度名称 | 当前维度下的分类名称。未钻取时显示"客户"或"合同类型"（由二级维度选择器决定）；钻取到销售产品层级时显示"销售产品"名称 | 接口返回的 breakdowns 列表 | 文本 |
| 收入 | 该维度项在选定期间内的营业收入总额 | 接口返回（breakdowns 中对应记录的 revenue 字段） | 万元，保留两位小数 |
| 收入贡献度 | 该维度项的收入占总收入的百分比，反映该项对整体收入的贡献程度。计算公式：该项收入 / 总收入 x 100% | 接口返回（breakdowns 中对应记录的 revenue_contribution 字段） | 百分比，保留两位小数 |
| 毛利 | 该维度项在选定期间内的毛利总额，即收入减去不含税成本 | 接口返回（breakdowns 中对应记录的 gross_profit 字段） | 万元，保留两位小数 |
| 毛利贡献度 | 该维度项的毛利占总毛利的百分比，反映该项对整体毛利的贡献程度。计算公式：该项毛利 / 总毛利 x 100% | 接口返回（breakdowns 中对应记录的 gross_margin_contribution 字段） | 百分比，保留两位小数 |
| 毛利率 | 该维度项的盈利水平，计算公式：毛利 / 收入 x 100%。反映每单位收入中有多少是毛利 | 接口返回（breakdowns 中对应记录的 gross_margin 字段） | 百分比，保留两位小数 |
| 负毛利产品数量 | 该维度项下毛利率为负的订单/产品数量。用于识别哪些产品或客户存在亏损 | 接口返回（breakdowns 中对应记录的 neg_margin_order_count 字段） | 整数 |
| 负毛利金额 | 该维度项下负毛利部分的金额合计（即亏损金额）。用于量化亏损规模 | 接口返回（breakdowns 中对应记录的 neg_margin_amount 字段） | 万元，保留两位小数 |

### （三）趋势分析指标（用于同比/环比展示）

| 指标名称 | 计算说明 | 数据来源 | 格式 |
|---------|---------|---------|------|
| 收入同比增长率 | （当期收入 - 去年同期收入）/ 去年同期收入 x 100%。对比基期选择"同比"时展示 | 由当期与去年同期数据计算得出 | 百分比 |
| 毛利额同比增长率 | （当期毛利额 - 去年同期毛利额）/ 去年同期毛利额 x 100% | 由当期与去年同期数据计算得出 | 百分比 |
| 毛利率同比变化 | 当期毛利率 - 去年同期毛利率。单位为百分点（pp） | 由当期与去年同期毛利率差值计算得出 | 百分点 |
| 负毛利产品占比同比变化 | 当期负毛利产品占比 - 去年同期负毛利产品占比。单位为百分点（pp） | 由当期与去年同期数据计算得出 | 百分点 |
| 收入环比增长率 | （当期收入 - 上期收入）/ 上期收入 x 100%。对比基期选择"环比"时展示 | 由当期与上期数据计算得出 | 百分比 |
| 毛利额环比增长率 | （当期毛利额 - 上期毛利额）/ 上期毛利额 x 100% | 由当期与上期数据计算得出 | 百分比 |
| 毛利率环比变化 | 当期毛利率 - 上期毛利率。单位为百分点（pp） | 由当期与上期毛利率差值计算得出 | 百分点 |
| 负毛利产品占比环比变化 | 当期负毛利产品占比 - 上期负毛利产品占比。单位为百分点（pp） | 由当期与上期数据计算得出 | 百分点 |

## 三、筛选条件说明

| 筛选条件 | 类型 | 说明 | 影响范围 |
|---------|------|------|---------|
| 周期维度 | 枚举（月度/季度/年累计/自定义期间） | 决定数据聚合的时间粒度。选择"月度"时按月展示，选择"季度"时按季展示，选择"年累计"时按年初至选定月份累计展示 | 影响所有指标的计算范围 |
| 报告期 | 字符串（如 "2025Q1"、"2025M01" 等） | 选择具体的期间。配合周期维度使用，决定数据的时间范围 | 过滤所有指标，仅保留该报告期相关数据 |
| 对比基期 | 枚举（同比/环比/自定义期间） | 同比：与去年同期对比；环比：与上一期对比；自定义期间：手动选择对比区间 | 影响趋势指标（增长率、变化值）的计算 |
| 产品线 | 字符串 | 选择要分析的具体产品线。未选择时展示公司整体数据，选择后仅展示该产品线数据 | 过滤所有指标及明细数据 |
| 二级维度 | 枚举（客户/合同类型） | 仅在未钻取状态下可用，决定明细表按客户维度还是合同类型维度展示 | 仅影响明细表的分组方式 |

## 四、注意事项

1. **金额单位：** 前端展示的收入、毛利均以"万元"为单位。KPI 卡片默认显示整数，明细表中保留两位小数。后端返回的原始数值需经 `toWan()` 或 `formatWan(value, 2)` 转换。

2. **毛利率计算：**
   - 接口返回的毛利率为比值形式（0~1），前端展示时通过 `formatPercent()` 转换为百分比。
   - 若收入为零或成本数据缺失，毛利率无法计算，应显示为空。

3. **部门权限控制：** 所有数据均按用户的部门权限（bgbu 字段）过滤。非管理员用户只能看到其所属部门的数据，管理员用户可看到全部部门数据（bgbu = 'ALL'）。部门权限由登录用户的 `user.department` 和 `user.role` 参数决定。

4. **报告期匹配规则：** reportId 采用前缀匹配方式（`LIKE '{report_id}%'`），例如 reportId 为 "2025" 时，会匹配 "2025Q1"、"2025M01" 等所有以 "2025" 开头的期间。

5. **钻取机制：** 点击产品线明细表中的产品名称，可钻取到销售产品名称层级。钻取后，KPI 指标和明细数据均按该销售产品重新聚合。顶部会出现"返回产品线"按钮。

6. **同比与环比说明：**
   - 同比（YoY）：(当期值 - 去年同期值) / 去年同期值 x 100%
   - 环比（MoM）：(当期值 - 上期值) / 上期值 x 100%
   - 选择产品线筛选后，同比/环比的分母（基期数据）也按相同产品线过滤，确保对比口径一致。未选择时使用公司整体数据。
   - 增长率超过100%属于正常现象，表示当期收入超过基期一倍以上。

7. **数据聚合层级：** 产品分析页面通过核心指标接口（`GET /metrics/core`）获取数据，支持两种维度：`product_line`（产品线层）和 `sales_product`（销售产品层，钻取状态下使用）。明细数据通过 breakdowns 字段返回，包含收入、毛利、毛利率及贡献度等指标。
