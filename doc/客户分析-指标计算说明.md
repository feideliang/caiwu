# 客户分析 — 指标计算说明

## 一、页面概览

客户分析页面用于按客户维度拆解分析收入、毛利等核心财务指标，支持以下分析场景：

- **客户贡献排名**：展示各客户的收入规模排名，识别核心客户
- **毛利率分析**：查看不同客户的盈利水平差异
- **合同类型对比**：切换至合同类型维度，对比不同合同类型的收入与毛利
- **产品层级下钻**：点击客户名称可下钻至销售产品层级，查看该客户购买的产品明细

页面支持按周期维度（月度/季度/年累计/自定义期间）、客户、对比基期（同比/环比）进行筛选。管理员可查看全部数据，非管理员仅可查看本部门数据。

## 二、指标列表

### 2.1 汇总指标（KPI 卡片）

页面顶部展示 4 个核心 KPI 卡片：

| 指标名称 | 前端展示名称 | 计算说明 | 数据来源字段 | 格式 |
|---------|------------|---------|------------|------|
| 收入 | 收入 | 当期营业收入总额 | `summary.revenue` | 万元，整数 |
| 毛利额 | 毛利额 | 当期毛利总额，即收入减去成本 | `summary.gross_profit` | 万元，整数 |
| 毛利率 | 毛利率 | 毛利额占收入的百分比 | `summary.gross_margin` | 百分比，保留两位小数 |
| 客户集中度 | 客户集中度Top10 | 收入排名前10的客户收入之和占总收入的百分比 | `summary.customer_concentration_top10` | 百分比，保留两位小数 |

每个 KPI 卡片可显示趋势箭头（同比或环比），趋势值根据"对比基期"选择自动切换：
- 选择"同比"时，显示 `revenue_yoy_growth`、`gross_profit_yoy_growth`、`gross_margin_yoy_change`
- 选择"环比"时，显示 `revenue_mom_growth`、`gross_profit_mom_growth`、`gross_margin_mom_change`

明细表格及下钻中展示的指标：

| 指标名称 | 前端展示名称 | 计算说明 | 数据来源字段 | 格式 |
|---------|------------|---------|------------|------|
| 维度值 | 客户名称 / 合同类型 / 销售产品 | 当前维度的具体取值 | `dimension_value` | 文本 |
| 收入 | 收入(万元) | 按维度分组的营业收入合计 | `revenue` | 万元，保留两位小数 |
| 收入贡献度 | 收入贡献度 | 该维度值的收入占总收入的百分比 | `revenue_contribution` | 百分比 |
| 毛利额 | 毛利(万元) | 该维度值的毛利额（收入减成本） | `gross_profit` | 万元，保留两位小数 |
| 毛利贡献度 | 毛利贡献度 | 该维度值的毛利额占总毛利额的百分比 | `gross_margin_contribution` | 百分比 |
| 毛利率 | 毛利率 | 毛利额占收入的百分比 | `gross_margin` | 百分比 |

## 三、筛选条件说明

| 筛选条件 | 说明 | 影响范围 |
|---------|------|---------|
| 周期维度 | 可选择月度、季度、年累计或自定义期间，决定数据聚合粒度 | 影响所有指标计算和趋势展示 |
| 期间选择 | 根据周期维度选择具体期间，如"2024-Q1"或"3月累计" | 影响所有指标计算 |
| 对比基期 | 选择同比（与去年同期比）或环比（与上期比），或自定义对比期间 | 影响 KPI 趋势箭头和增长率 |
| 客户 | 选择特定客户后，所有指标按该客户过滤，同比/环比的分母也按相同客户计算 | 影响所有汇总和明细数据 |
| 对比维度 | 仅在选择客户后出现，可选择按"客户"或"合同类型"维度展示 | 影响明细表格和图表的分组方式 |
| 用户角色范围 | 管理员可查看全部数据；非管理员仅可查看本部门数据 | 限制数据可见范围，不影响计算公式 |

## 四、注意事项

1. **金额单位**：后端存储的金额为原始值（元），前端通过 `toWan()` 函数除以 10,000 转换为"万元"展示。KPI 卡片取整显示，明细表格保留两位小数。

2. **成本缺失处理**：当某维度下成本数据为零或缺失时，毛利额和毛利率无法计算。后端返回 `calculable = false` 或 `missing_fields` 数组，前端应展示为"--"而非"0"。

3. **毛利率口径**：所有维度的毛利率统一返回百分比形式（如 25.5 表示 25.5%），前端统一使用 `formatPercent()` 函数展示为 "25.50%"。

4. **客户集中度 Top10**：计算公式为"收入排名前10的客户收入之和 / 全部客户收入总和 x 100%"。当使用 Top-N 优化查询时，分母取自 SQL 汇总的总收入（`__total__` 键），确保分子分母口径一致。结果上限为 100%。

5. **直签指标**：直签客户收入、收入占比、毛利、毛利率已在后端计算并返回至前端，在仪表盘"核心盈利能力"卡片中展示。仅在公司/事业部级别可用，产品或客户过滤时不展示。

6. **核心市场线 / 最具价值市场线**：这两个指标基于事业部（bgbu）维度计算，分别取收入最高和毛利最高的事业部。仅在公司/事业部级别可用。

7. **负毛利指标**：
   - 负毛利订单占比：毛利为负的订单数 / 有收入的订单总数 x 100%
   - 负毛利产品占比：毛利为负的产品数 / 全部产品数 x 100%
   - 两者均在仪表盘"增长与质量"卡片中展示，含对应的负毛利金额。

8. **L4 订单级别**：在 L4 交易明细层级，`children_count` 恒为 0，无实际业务含义。

9. **部门范围限制**：非管理员用户的筛选结果会自动叠加本部门过滤条件，此限制由后端中间件层强制实施，前端无需额外处理。

10. **数据质量提示**：当数据不完整时，页面顶部会显示警告信息，列出缺失字段（`missing_fields`）和警告内容（`warnings`）。
